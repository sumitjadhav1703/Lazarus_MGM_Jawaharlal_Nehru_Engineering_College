# CardioTwin ML improvement plan

Goal: implement internet-informed, measurable ECG feature and grouped-learning improvements without treating manufactured fixtures as clinical validation. User explicitly requested research and implementation; existing authorization includes useful parallel subagents. Current baseline: artifacts/final-demo and reports/demo-evaluation (38 passing tests), preserved before changes. Source snapshot: /tmp/cardiotwin-before-ml-improvements.tar.gz.

Architecture: retain annotation-free causal features → frozen grouped/calibrated model → shared warning policy. Extend the existing modules, use installed NumPy/SciPy/sklearn/XGBoost, and write a development-only ablation runner. New feature semantics have an explicit version; previous releases cannot silently run with changed extraction.

Constraints: strict uncertain-N labels; trailing600s/inclusive+120–600s/cadence30s; unchanged quality limits; earlier-only baseline; train-only transforms and sample weights; held-out calibration remains at natural monitoring prevalence; validation chooses operating points; no test-driven tuning. Real clinical training remains gated. No SMOTE, online retraining, deep model, P-wave diagnosis or unsupported clinical confidence.
