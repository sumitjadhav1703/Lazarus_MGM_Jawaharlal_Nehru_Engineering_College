# Shared contracts

Paths under src/cardiotwin; JSON-safe payloads with seconds relative to record start; finite numbers or null (never JSON NaN). Raw patient identifiers are pseudonymized. Clinical normalized values are numeric and include per-field availability.

## Config
`load_config(path=None) -> dict`. default.json keys: version, target {history_seconds:600,gap_seconds:120,horizon_seconds:600,cadence_seconds:30,min_episode_seconds:30,washout_seconds:600}, quality {max_missing_fraction:.05,max_flatline_fraction:.2,min_peaks:10,max_lead_disagreement:.5}, baseline {minimum_updates:5,max_updates:240}, alert {threshold:.8,release_threshold:.6,persistence_seconds:60,cooldown_seconds:600,max_false_warnings_per_hour:null,min_event_sensitivity:null}, audit {min_event_subjects:12,min_test_event_subjects:3}, seed:42. Defaults are experimental, unapproved. Config validates positive timing and release <= threshold, explicit budget values for training policy selection.

## Data agent
`RecordInfo` dataclass with record_id:str, patient_id:str, path:str, fs:float, duration_seconds:float, annotated:bool, clinical:dict, metadata_audit:list, signal_hash:str|None, start_time:str|None. `list_records(data_dir:Path) -> list[RecordInfo]`; `read_signal(record:RecordInfo,start_seconds:float,end_seconds:float)->np.ndarray` shape (n,channels), trailing [start,end). `read_intervals(record)->list[RhythmInterval]`. Support WFDB and synthetic NPZ+manifest JSON.
`RhythmInterval(start:float,end:float,rhythm:str)` accepts 'AF','other','unknown' (other adequately labelled non-AF, no proven sinus claim). Label N defaults conservative unknown unless dataset semantics support adequate non-AF exclusion.
`eligible_onsets(intervals,duration,config)->list[float]`; `label_at(t,intervals,duration,config)->(int|None,str|None)` positive inclusive [t+gap,t+horizon], negative adequate through horizon; current_AF, gap, history, future, unknown, washout excluded.
`audit_dataset(data_dir,output_dir,config)->dict`, writes records.json, cohort.csv, field_audit.json, audit.json, splits.json. splits maps patient_id to train/calibration/validation/test. Split once deterministically from seed, ensuring event-bearing groups; audit feasible flag gates real training; synthetic explicit flag distinct. manifests capture content duplicates and overlapping recordings and exclusions; audit eligible events require clean signal/history if available.
`make_demo(output_dir,config)->dict` reproducible synthetic ECG/metadata/intervals, all clearly synthetic; enough independent patients/positive+negative windows to exercise training/calibration/test plumbing.

## Features (root)
`extract_features(signal:np.ndarray,fs:float)->dict` receives ONLY trailing available ECG. Keys ecg_hr,ecg_rr_mean,ecg_sdnn,ecg_rmssd,ecg_pnn50,ecg_hr_trend,quality_missing,quality_flatline,quality_lead_disagreement,quality_peak_count,quality_peak_reliability,quality_saturation; finite numeric or None.
`feature_row(signal,fs,clinical,baseline,config)->(dict,dict)` returns features including clinical_* and baseline_* numeric values, plus quality {accepted:bool,reason:str|None,...}. `update_baseline(baseline,features,config)->dict` running mean stats, prior state only; baseline mean/count bounded EMA after max_updates. Missing values preserved for training imputation. `CLINICAL_FIELDS` allowlist shared from features or data; incoming clinical must be preaudited by data agent (timing).

## Model agent
`Predictor.load(path:Path)->Predictor`, `.version:str`, `.config:dict`, `.predict(features:dict)->dict` {risk:float,evidence:list[{feature,value,contribution}],uncertainty:str}. Trusted local artifacts only; binary checksum plus embedded ordered schema/config must agree with release sidecars. Feature schema excludes IDs, label/time/file path. Persist model.joblib, manifest.json, config.json, feature_schema.json, splits.json, model_card.md.
`train_dataset(data_dir,audit_dir,output_dir,config,synthetic=False)->dict`; builds training rows from causal trailing feature_row + prior baseline, uses offline label_at separately; calibration distinct patients; all required comparisons evaluated same validation stream/policy, select operating threshold meeting explicit budget/sensitivity; if none, fail acceptance honestly. Final test isolated in evaluate command after freeze. `evaluate_artifact(data_dir,audit_dir,artifact_dir,output_dir)->dict` full held-out chronological replay incl rejected windows, one-to-one event match, monitoring denominators, probability metrics, patient bootstrap confidence intervals, burden/missed events/latency/hardware and calibration data.
Evaluation reusable `match_warnings(warnings,onsets,gap,horizon)` and `evaluate_stream(rows,events,config)` may have signatures chosen by agent and documented.

## Runtime/API (root)
`TwinService(data_dir,db_path,config,model_dir=None)` synchronous serialized replay; runtime consumes RecordInfo and signal only (NEVER read_intervals). `.patients()`, `.state(patient_id)`, `.step(patient_id,steps=1)`, `.control(patient_id,action)` actions start/pause/reset; `.warnings(patient_id)`, `.review(patient_id,warning_id,status,note)` status pending/reviewed/dismissed; `.metrics()`. Each replay step advances cadence with bounded retained buffer; persistent cursor/baseline/alert/state atomic. With no model forecast unavailable 'model_not_loaded'. Restarts require same input fingerprint+config+model to continue, otherwise conflict.
Endpoints: GET /api/health, /api/patients -> list summaries; GET /api/patients/{id}/state -> full state; POST /api/patients/{id}/replay body {action:'start'|'pause'|'reset'|'step',steps:1}; GET /api/patients/{id}/forecast; GET /api/patients/{id}/warnings -> list; POST /api/patients/{id}/warnings/{warning_id}/review body {status,note}; GET /api/metrics.
State shape: patient_id, record_id, clinical, timestamp, duration_seconds, replay_status ('paused'|'running'|'complete'), baseline {count,means}, quality, forecast {available,risk,timestamp,target_start,target_end,model_version,reason,evidence,uncertainty,quality,baseline}, warnings, timeline, features, feature_history, ecg {times,leads,fs}, mode:'historical_simulation', provenance:'synthetic'|'SHDB-AF'. GET state supplies bounded downsampled last 10s trace and trailing feature history.
Dashboard polls state, POST start sets running and API background replay ticks cadence under accelerated configurable playback; step explicit supported. Evaluation absent returns {status:'not_evaluated',limitations:[...]}; displays unavailable not zeros.
